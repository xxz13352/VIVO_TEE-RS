# KSU WebUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a static KernelSU WebUI that safely manages TEESimulator-RS runtime configuration.

**Architecture:** `app.js` exports pure parsing, validation, serialization, and command builders for Node tests, then initializes browser rendering only when `document` is defined. The static page imports a local copy of the KernelSU bridge and has no build or network dependency.

**Tech Stack:** Native ES modules, HTML, CSS, Node built-in test runner, KernelSU JavaScript bridge 3.0.2.

## Global Constraints

- All runtime WebUI files live beneath `module/webroot` and are included by the existing Gradle Sync task.
- UI copy is Simplified Chinese; source defaults to ASCII unless syntax requires otherwise.
- Every editable value is validated before serialization.
- File writes use UTF-8 Base64 content from `TextEncoder` plus `btoa`, a same-directory temporary path, `chmod 0644`, then `mv -f`.
- Browser commands check `errno`, report errors inline, and refresh in-memory state after successful writes.
- Use system light and dark themes, visible focus states, reduced-motion support, 44px touch targets, and a one-column mobile layout.

```js
  parseTargets, serializeTargets, parsePatchLevels, serializePatchLevels,
  buildAtomicWriteCommand, buildClearPersistedKeysCommand,
} from '../../module/webroot/app.js';

test('parses target mode and keybox contexts', () => {
  assert.deepEqual(parseTargets('com.example.auto\n[alt.xml]\ncom.example.make!\ncom.example.patch?\n'), [
    { packageName: 'com.example.auto', mode: 'auto', keybox: 'keybox.xml' },
    { packageName: 'com.example.make', mode: 'generate', keybox: 'alt.xml' },
    { packageName: 'com.example.patch', mode: 'patch', keybox: 'alt.xml' },
  ]);
});

test('does not interpolate raw text into atomic write commands', () => {
  const command = buildAtomicWriteCommand('/data/adb/tricky_store/target.txt', 'bad; reboot');
  assert.match(command, /base64 -d/);
  assert.doesNotMatch(command, /bad; reboot/);
  assert.match(command, /mv -f/);
});

test('only clears persisted key files', () => {
  const command = buildClearPersistedKeysCommand();
  assert.match(command, /persistent_keys/);
  assert.match(command, /-name '\*\.bin'/);
  assert.doesNotMatch(command, /rm -rf/);
});
```
